# 🐞 Defect Reporting Approach

A strong defect report should make the issue **reproducible, understandable, and actionable**.

```text
Bug ID
  ↓
Module / Page
  ↓
Bug Summary
  ↓
Steps to Reproduce
  ↓
Expected Result
  ↓
Actual Result
  ↓
Severity / Priority
  ↓
Environment
  ↓
Evidence
  ↓
Retest Result
```

**Defect quality principles:** `Clear` · `Reproducible` · `Evidence-Based` · `Prioritized` · `Traceable`
