## 🐛 Bug Hunter Workflow

```text
📝 Requirement
      │
      ▼
🧪 Test Scenario
      │
      ▼
▶️ Execute
      │
      ├── PASS ───────────────► Continue
      │
      └── FAIL
          │
          ▼
      🐞 Reproduce
          │
          ▼
      📸 Capture Evidence
          │
          ▼
      📋 Report Defect
          │
          ▼
      👨‍💻 Developer Fix
          │
          ▼
      🔄 Retest
          │
          ├── FAIL ───────────► Reopen
          │
          └── PASS
              │
              ▼
          🔁 Regression
              │
              ▼
          ✅ Verify & Close
```

### Defect Report Formula

**Bug ID → Module/Page → Steps → Expected → Actual → Severity/Priority → Environment → Evidence → Retest**

**Clear · Reproducible · Actionable · Evidence-Based · Prioritized · Traceable**
