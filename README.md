## 🐛 Bug Hunter Workflow

```text
📝 REQUIREMENT
      │
      ▼
🧪 TEST SCENARIO
      │
      ▼
▶️ EXECUTE ─────── PASS ───────► CONTINUE
      │
      └── FAIL
           │
           ▼
      🐞 REPRODUCE
           │
           ▼
      📸 EVIDENCE
           │
           ▼
      📋 DEFECT REPORT
           │
           ▼
      👨‍💻 FIX
           │
           ▼
      🔄 RETEST
         /     \
      FAIL     PASS
       │         │
       ▼         ▼
    REOPEN    🔁 REGRESSION
                 │
                 ▼
             ✅ VERIFIED
                 │
                 ▼
              CLOSED
```

**Defect formula:** `Bug ID → Module → Steps → Expected → Actual → Severity/Priority → Environment → Evidence → Retest`
