## 🐛 Bug Hunter Workflow

```text
EXECUTE
  ↓
PASS ───────────────► CONTINUE
  │
 FAIL
  ↓
REPRODUCE
  ↓
CAPTURE EVIDENCE
  ↓
WRITE DEFECT
  ↓
COMMUNICATE
  ↓
FIXED
  ↓
RETEST
 ↙   ↘
FAIL  PASS
 ↓      ↓
REOPEN REGRESSION
          ↓
       VERIFIED
```

**Defect structure:** `Bug ID → Module/Page → Summary → Steps → Expected → Actual → Severity → Priority → Status → Environment → Evidence → Retest`
