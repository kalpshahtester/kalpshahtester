## Hi, I'm Kalp Shah 👋

**Manual QA Tester | Web Application Testing | WordPress QA**

I help improve website quality by testing real user journeys, identifying defects, documenting clear evidence, and verifying fixes. My approach is practical and user-focused: understand the requirement, explore the application, test expected and edge-case behaviour, and communicate findings so they can be resolved efficiently.

I currently work on website quality assurance, including WordPress websites, UI behaviour, responsive layouts, content accuracy, and regression testing.

## What I Work On

- **Manual testing:** Functional, UI, exploratory, positive/negative, regression, smoke, sanity, and retesting.
- **Web QA:** Navigation, forms, links, user journeys, browser compatibility, and responsive behaviour.
- **WordPress QA:** Page layouts, menus, content, media, forms, plugins, and common website workflows.
- **SEO quality checks:** Page titles, meta descriptions, heading structure, image alt text, and link validation.
- **Defect reporting:** Reproduction steps, expected vs. actual results, severity, priority, screenshots, and retest evidence.
- **Test documentation:** Test scenarios, test cases, test execution, RTM, bug reports, and test summaries.

**Understand requirements → Plan tests → Design test cases → Execute → Report defects → Retest fixes → Run regression → Verify**

A useful defect report should make the issue easy to understand and reproduce. I aim to include the environment, clear steps, test data, expected and actual results, severity/priority, and supporting screenshots or recordings.
